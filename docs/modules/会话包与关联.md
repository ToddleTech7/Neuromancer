# 模块：会话包与 join（`cave_session_pack.py` · `cave_join.py`）

更新：2026-10-26 · 本页只讲"落盘契约"与"关联方式"；能力边界见 [当前进度](../当前进度.md)。

## 1. 职责

- **会话包**：把一次会话落成一个可审计目录（原始事件、图、备注、派生全分开）。
- **join**：把客户端会话与服务端 op log 对上，并**如实标注匹配方式**，不猜。

**不做**：不改写原始事件；不用"时间相近"直接宣布匹配；不在 join 里生成训练标签。

## 2. 接口

**目录契约**

```
<session_id>/
  manifest.json          统计/健康/完整性/provenance/collector 配置与 capabilities
  client/events.jsonl    原始事件（一行一条，带 seq + t_wall；同会话重存时整份重写）
  client/shots/shots.jsonl 每张图的元数据（state_id/w/h/capture_status/readback_via）
  client/shots/*.png     图本体
  client/notes.jsonl     人工显式表达（书签/备注）
  derived/               派生结果（可重算，不参与审计）
```

**关键函数**

| 函数 | 输入 → 输出 |
|---|---|
| `pack_session(pack, out_dir, legs, reasons)` | 内存包 → 目录包（含 integrity / provenance） |
| `load_session(path)` | 目录或 JSON → 统一 dict（`events` / `shots` / `pack_dir`） |
| `ctype(ev)` | 事件 → 规范名（新名优先，回落 `legacy_type`） |
| `health_summary(events, gaps_hint=None)` | 事件流 → seq 断档/缺口/丢弃摘要 |
| `join_session(pack, ops, pre_s, post_s)` | 会话 + op 列表 → 匹配记录 + 时钟估计 + 上下文 |

**join 的三级匹配（level 决定可信度，不许混用）**

| level | 含义 | 用法 |
|---|---|---|
| `exact-anchor` | 客户端 `api_operation_id` 与服务端 `op_id` 相同 | 可直接当"这次提交"用 |
| `anchor-estimated` | 用响应 `Date` 头/回执时间推的时钟 | 只能做时间线，不能当提交事实 |
| `window` | 只有时间窗 + root 交集 | 只能做"可能相关"，**不得**当匹配 |

## 3. 设计要点（不变量）

1. **同一会话重存先备份旧包到 `.old_*`，再写新目录；不同会话同名加 `__<时间戳>`**（`_unique_dir`）。
   `manifest.previous_pack` 记录旧包路径。`.old_*` 不参与“最新包”选择；确认后可删。
2. **原始 / 派生 / 人工 三分**：`client/*` 是原始，`derived/*` 可重算，`notes.jsonl` 是人工显式表达。
3. **provenance 逐段标注**：service_facts / visual_assets / client_process / submit_execution / join，各取 `real|simulated|unknown` + reason。
4. **0 假匹配是硬指标**：宁可 `window` 也不升级成 `exact-anchor`；夹具里专门放"时间靠近但 op 不同"的负例。
5. **时钟要带不确定度**：`estimate_clock` 给 `offset_ms` 与 `uncertainty_ms`，下游据此决定能否按毫秒对齐。
6. **完整性可数**：`integrity.n_png`、事件数、缺口数写进 manifest，评审时先看这些数字。

## 4. 实现入口

```bash
# 落包（recorder 导出时自动调用；也可从 JSON 补建）
python3 scripts/cave_session_pack.py <session.json>

# join：会话 ↔ op log
python3 scripts/cave_join.py <会话包或JSON> <ops.json> [--pre-s 15 --post-s 3]

# 夹具
python3 scripts/verify_cave_join.py          # 24 项，含负例
```

## 5. 验证

| 断言 | 守住什么 |
|---|---|
| join 夹具 24/24（含 0 假匹配） | 不把"时间靠近"当匹配 |
| 事件数与 seq 无断档 | 记录连续性 |
| `integrity.n_png` 与 shots 条数一致 | 图不会被"记了但没落" |
| `manifest.config` 存在 | 粒度可追溯（50ms / 全量） |
| demo 全链 PASS（提交腿 simulated，其余 real） | 五段 provenance 没被写成一个"real" |
