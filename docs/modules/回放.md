# 模块：回放与保真度（`cave_replay_viewer.py` · `verify_replay_fidelity.py`）

更新：2026-10-26 · 本页回答"**能不能把当时那一帧重画出来**"，以及这个结论的边界。

## 职责

- **回放**：拿会话里的完整 state，在真 Neuroglancer 里恢复，只读。
- **保真度**：把"恢复后渲染出的画面"和"当时录到的图"逐张比对，给一个数字。

**不做**：不改历史数据、不允许写操作、**不用"画面像"冒充"数据版本一致"**。

## 接口

**恢复点选择**（`collect_states(pack, limit=None, source='auto')`）

| source | 行为 |
|---|---|
| `auto`（默认） | 优先用每个 `viewer.state-change` 的完整 state；没有则退回 checkpoint |
| `state` | 只用带 state 的变化点（旧包会返回空） |
| `checkpoint` | 只用 30s 剖点（调试/对比用） |

返回 `[{state_id, t_wall, state, source}]`；跳过 `state_partial` 与 `state_sha` 重复项。

**命令行**

```bash
python3 scripts/cave_replay_viewer.py <会话包> \
    [--source auto|state|checkpoint] [--max-points N] [--hold 秒] [--headed]
# 产物：derived/replay/replay_manifest.json + ckpt_XXX.png

python3 scripts/verify_replay_fidelity.py <会话包> [--max-pairs 8] [--out path] \
    [--html path] [--settle 6] [--min-colored 0.05] [--no-self-check]
# 产物：replay_fidelity.json + replay_compare.html + derived/replay_frames/*.png

python3 scripts/replay_manual_session.py --pack <包> [--seek-t 140] \
    [--start manual_2 --end manual_3] [--mesh-wait 35] [--compare-all] [--video]
# --seek-t：只重放到第 N 秒（自动选前后两个锚点）；--compare-all：整图比像素
# （默认只比 4panel 的 2D 三块，排除 3D 面板的 LOD 波动）

python3 scripts/verify_replay_reset.py [--headed]
# 本地无网：验证"缺省即默认"的复位语义（脏→干净→脏），4 项断言
```

## 设计要点（不变量）

1. **恢复单位是"一个时刻"**，不是"一个 30 秒窗口"。所以每条 `state-change` 都必须自带完整 state。
2. **恢复优先级 fallback 要标出来**：`source='checkpoint'` 表示"这段中间态恢复不了"，不许写成等价。
3. **只读门禁**：注入 guard，回放态下拒绝一切非 GET 的 `/api/` 请求，并在 manifest 写 `blocked_attempts` 与自测结果。
4. **缺省即默认（最容易漏的一条）**：state 里没有这个键 = 当时是默认值。下发前必须把
   尺度/朝向/布局/选中**复位**，否则会沿用上一个回放点的值——位置对得上、画面是错的。
   守它的装置是 `verify_replay_reset.py`。
5. **"到位"= 多字段对上**，不是 position 一个数：位置/`crossSectionScale`/`projectionScale`/
   两个朝向/布局/切片可见性/局部视口/切片厚度/图层（名字·source·visible·opacity·segments·style）/坐标系，统一由
   `replay_state.compare()` 判定；回放器与保真度自检共用这一套，避免两处判据不一致。
6. **对齐靠闭环，不靠固定等待**：state 到位只说明参数设好，瓦片/分割可能还没画出来。
   先按包里的 `keyframe_paint.colored_min` 等一次（低于它就没有可比内容），然后
   **读一帧 → 跟当时那张图比一次 → 不一致就再等 0.5s 再读**，直到 NCC ≥ `--accept-ncc`
   或 `--settle` 预算用完；取最好的一次，并记 `settle_attempts` / `settle_ms`。
   为什么不拍一个“彩色占比阈值”：那个数两侧渲染本来就不一样（实测同一画面
   0.714 vs 0.662），调一个数只能把一种情况调对、另一种调错。
7. **不可比的帧要“单列”，不能藏**：
   - 采集侧已判 `capture_status='painted_partial'`（拍摄时彩色占比不达标）
     → 当证据不成立，**不参与比对**，只记 `n_skipped_partial_paint`；
   - 采集侧 `paint_stable=false`（拖动中拍的那一帧）→ 它与快门时 state 天然
     差一帧运动，比对不收敛时标 `motion_lag`，**不算回放错**；
   - 剩下的“既没收敛、也没解释”才计 `not_converged`（demo 里为 0 才 PASS）。
8. **尺寸不一致直接判 `skipped`**，不做缩放瞎比（1280×800 与 1400×900 不能混）。
9. **指标要能看见"内容不一样"**：灰度 NCC 对"分割叠加在不在"几乎不敏感（实测一张灰图
   vs 彩色分割图仍报 0.96）⇒ 同时报 `rgb_ncc` 与两边**彩色像素占比**；占比差 > 0.15
   记 `content_mismatch`。
10. **区分"回放不稳"与"记录/版本不一行"**：同一 state 连放两次算 `self_ncc`（噪声上界）。
    `self` 高而 `ncc` 低 ⇒ 记录或数据版本的问题；`self` 本身低 ⇒ 回放端不稳。
11. **阈值取保守值**：平均 NCC ≥ 0.90、最低 ≥ 0.80；**收敛帧**逐通道 NCC ≥ 0.90；
    自一致最低 ≥ 0.90；字段必须全对；内容必须一致。实测见 `docs/目录.md`。
12. **不声称版本**：manifest 里固定写三条 `visual_gaps`（分割不可回溯 / mesh 未重建 / V_loaded 未知）。
13. **回放帧必须落盘**（`derived/replay_frames/`）：只有数字没有图，人无法复核；
    `replay_compare.html` 三图并排（当时 / 回放#1 / 回放#2）+ 逐字段表。
14. **动作回放 ≠ state 回放**（`verify_action_replay.py`）：前者把 `input.pointer` /
    `input.wheel` **按原相对时间重新投递**（不喂最终 state），验的是“同一个人的同一次拖动
    再放一遍会不会停在同一个地方”。三条硬约束：
    - **修饰键是动作的一部分**：实测这个构建里裸 wheel 不动尺度，缩放绑定在 `ctrl+wheel`
      （6 → 0.54）；不重放 `modifiers` 就等于把缩放变成空操作；
    - **先过“动作有效性地板”**：动作没改变任何状态 ⇒ 后续“误差 0”是假绿（单测盖住：
      `test_action_effects.py`）；
    - **逐段比对**：每段动作后都有一个带完整 state 的 anchor，逐段比位置/尺度/朝向；
      末帧再与录制图做一次闭环比对（不够好就再等再读）。

## 实现入口

| 关注点 | 位置 |
|---|---|
| 恢复点选择 | `replay_state.collect_points()`（回放器与保真度共用） |
| 状态下发/复位 | 本地 demo server 的 `state <json>` 命令 → `_apply_state` |
| 视图指纹与比对 | `replay_state.py`：`fingerprint()` / `compare()` / `LIVE_FP_JS` |
| 只读门禁 | `GUARD_JS`（拦截非 GET `/api/`）+ 自测请求 |
| 读像素 | `READBACK_JS`（需 `cave_gpu_patch.js` 先注入） |
| 等画完 | `PAINT_JS` + `wait_paint()`（门前粗筛，只要求“有东西画出来”） |
| 闭环对齐 | `CMP_JS` 逐次对比 + `--accept-ncc`（一次不一致就再等再读） |
| 配对 | `collect_points()`：快门自带 state > state_id > 时间就近 3s |
| 对比页 | `compare_html()`（三图并排 + 逐字段 chip） |
| 动作回放 | `verify_action_replay.py`：录制真输入 → 新页面只喂输入 → 逐段比对 |

## 验证

| 断言 | 守住什么 |
|---|---|
| 每个 `viewer.state-change` 都带可恢复 state | 复刻粒度（不是 30s 剖点） |
| 每张关键帧都能配上可恢复点 | 恢复覆盖度 |
| 平均 NCC ≥ 0.90 / 最低 ≥ 0.80 | 复刻质量底线（写进 demo 的 PASS 条件） |
| 逐通道 NCC ≥ 0.90（仅收敛帧）/ 彩色占比差 ≤ 0.15 | 内容真的对上了（灰度 NCC 不够） |
| 回放自一致 ≥ 0.90 | 回放端稳定，差距可归因 |
| 字段全对（8 个字段） | 位置对 ≠ 同一帧 |
| 静止帧全部收敛（`not_converged = 0`） | 不是拿"还没画完"的帧当回放失败 |
| 未画完的帧计数两边对得上（包 vs 保真度） | 不可比的帧不会静默消失 |
| 恢复点来源分三类统计（state / shot_state / checkpoint） | 不把 fallback 当完整 |
| 写门禁 `self_test = replay_readonly_blocked` | 回放不会偷偷写 CAVE |
| 尺寸不一致 → `size_mismatch` 而非硬比 | 不制造假数字 |
| `verify_replay_reset` 脏→干净→脏 4 项 | "缺省即默认"没有被漏实现 |
| 动作回放 16 项（拖/缩/点/**键盘**逐段位级对上 + 末帧 NCC） | 不只 state 可恢复，**动作也可复现** |

## 已知不能（写清楚了，不靠猜）

| 限制 | 后果 |
|---|---|
| 公开栈没有历史分割快照 | 重画用的是**当前**数据；NCC 高只证明"画面可重建"，不证明"当时那版" |
| V_loaded 未记录（RF10 要 fork） | 只能靠"彩色占比"间接判断画完没有；不能证明当时具体加载了哪些 chunk |
| 运动中拍的帧与快门时 state 差一帧 | 那帧的 NCC 天然低一截；标 `motion_lag`，不当作回放失败 |
| 动作回放未覆盖工具切换 | 工具状态（`viewer.tool`）在本构建不可读，且 split/merge 语义需要可写后端（C0）；键盘已覆盖方向键/切片/吸附 |
| 历史 mesh 未重建 | 3D 视图里的 mesh 是现在生成的，不是当时的 |
| 3D 视锥未采 | 多视角布局里 3D 面板只能近似 |
| 布局默认值写死 `4panel` | 本地 demo viewer 的创建默认；换部署需重测 |
| 相机朝向只能比到四元数容差 | 极小的旋转差（<1e-3）算一致 |
