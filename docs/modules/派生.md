# 模块：派生（`cave_episodes.py` · `cave_derive.py`）

更新：2026-10-26 · 本模块属于后处理。派生层怎么切不影响"记录是否忠实"。

## 1. 职责

把原始事件算成可重算的索引：时间线归一化、观察片段（L2）、无编辑判定。
**不做**：不改原始事件、不承诺语义、**当前不做 L1 工作段与多版本阈值**（见 [已定决策](../已定决策.md) §0）。

## 2. 接口

```bash
python3 scripts/cave_episodes.py <会话包>
# 产物：derived/normalized.json、derived/episodes.jsonl
# 另有 manifest/normalized 里的 sampling 字段（回显输入粒度）
```

| 函数 | 作用 |
|---|---|
| `normalize(events)` | seq 断档 / 单调序 / 墙钟漂移；输出修正后时间轴与问题清单 |
| `derive_episodes(events)` | 切 L2 片段：空间跳变 + 时间间隔；带 `trigger`/`extra_triggers`/`policy_version` |
| `_all_idle_segments` / `_idle_for` | 静默区间（全段算一次，按开始时刻归属单一片段） |
| `_hover_summary(evs, t_end)` | 指针悬停段（`viewer.focus.picked`）→ `derived/hover.json` + 每段 `hover` |
| `no_edit` / `disposition` | `no_edit` 是**事实**；`disposition` 默认 `unknown`，只有显式声明才升级 |

**当前策略常量**（`POLICY`，默认面向真实会话）

| 键 | 默认 | 含义 |
|---|---|---|
| `gap_ms` | 30000 | 相邻事件静默超过此值 → 切段 |
| `jump_nm` | 50000 | 视角中心跳变超过此值 → 切段 |
| `idle_ms` | 2000 | 输入静默超过此值 → 记一段 idle（不切段） |
| `min_events` | 3 | 少于这么多个事件的残片并入相邻段 |
| `mergeable_reasons` | `('spatial_jump',)` | 只有跳变切出的段可被合并回邻段 |

## 3. 设计要点（不变量）

1. **派生可重算**：删掉 `derived/` 不影响任何结论；所有判断都带 `policy_version`。
2. **时间切分不可被 `min_events` 吞掉**：静默切出的段即使很短也保留，否则时长与 idle 会失真。
3. **idle 只算一次**：跨片段边界的静默归给"最后那一下输入所在的段"，不在两边重复计。
4. **`no_edit` 是事实，`disposition` 是判断**：前者由事件决定，后者缺省 `unknown`，不许用"后来没提交"反推"当时没看"。
5. **不把片段叫"任务"**：没有任务系统，边界是规则推断；用它的地方必须承认是 `auto.rule`。
6. **阈值只在派生层**：改阈值不触碰原始数据，也不需要重录。
7. **hover 只回答“指针压在哪个段上多久”**，不推断“看了/判断了/觉得它有错”。
   三条必须跟着产物走（`caveats` 字段里有）：`viewer.focus` 是**变化才发**
   （停住没新样本，时长算到下一次变化）；最后一次标 `open_spans`；
   短于采样点的划过会丢，次数与时长都是**下界**。
8. **“没人悬停”与“取不到值”必须分开**：`status = no_samples / no_picked / ok`。
   实测本地 demo 与公开 minnie65 的 97 条 `viewer.focus` 里 `picked` 全空
   （前者没层、后者坐标在数据外 + 瓦片没加载），不标出来就会被读成“人从不悬停”。

## 4. 实现入口

| 关注点 | 位置 |
|---|---|
| 策略常量 | `cave_episodes.POLICY` |
| 归一化 | `normalize()` |
| 切分 | `_split_boundaries()` / `derive_episodes()` |
| 编辑判定 | `_is_edit()`：`ctype=='edit.request'` 或 `api.request and write` |
| op 演化 | `cave_derive.py`（op 存活/演化，输入是 op log 不是会话） |

## 5. 验证

| 断言 | 守住什么 |
|---|---|
| 15 项单测（`test_episodes.py`） | 切分/合并/idle 归属/时钟的语义 |
| 时间间隔段不被合并 | 时长与 idle 不失真 |
| idle 跨边界只归一次 | 不双计、不丢失 |
| 脚本已知切点 2/2 找回（demo） | 管道通、不漏切（**不是**真人边界准确率） |
| 派生结果带输入粒度（`sampling`） | 下游知道这份数据是 50ms 还是全量 |

## 6. 暂缓与开放

| 项 | 状态 | 原因 |
|---|---|---|
| **L1 工作段**（分钟级"任务替代品"） | **暂缓** | 复刻不需要分段；语义层未定 |
| **三版本阈值并存**（loose/normal/tight） | **暂缓** | 没有真人数据校准，先不做 |
| **PP08 弱监督动作标签** | 未做 | 原料（gesture + 片段）已有，规则没定 |
| **PP09 重点观察候选排序** | 未做 | 需要先定义"重点"的单位 |
| 真人边界准确率 | 不打算做 | 需要人勾线 15–60 分钟，用户已决定不投 |
