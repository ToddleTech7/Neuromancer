# v1 发布清单（不依赖真实 CAVE 的部分）

目标：发布一个**单用户、本机/SSH 隧道使用**的采集—落包—回放—派生工具。
真实 CAVE 的现场验证仍是 C0，不阻塞 v1；v1 不承诺 `picked`、当前工具、chunk/LOD、历史版本。

## 一、v1 必须成立（发布门）

| # | 项 | 现状 | 验收 |
|---|---|---|---|

## 三、现在就能做、但 v1 可以不做

- 多用户/远程托管、鉴权、配额。
- 更细的 UI（缩略图墙、对比滑杆）。
- CSV/Parquet 全量导出、样本卡生产线。
- 自动更新、安装包/打包 dmg/exe。
- L1 工作段、三套阈值、PP08/PP09 语义标签。
- 真实 CAVE 的 `picked`/工具态/chunk/历史版本；这些等 C0 或后端。

## 四、v1 明确不做（写进发布说明）

| 不做 | 原因 |
|---|---|
| 承诺逐像素一致 | LOD/瓦片加载不由我们控制；NCC 只作参考 |
| 历史分割/EM 版本 | 需要后端版本指针 |
| 采集当前 merge/split 工具 | 当前构建 `viewer.tool` 不存在 |
| tile/chunk/mip 级渲染过程 | 真状态在 Worker，已评估成本过高 |
| 用停留时长推断“思考” | 停留只表示没输入 |
| 合成示例冒充真实采集 | 硬约束 |
| 整段长会话回放超 60nm | 当前 89s 包纯输入整段 4/6（末段 107.56nm）；分段 3/3（15.19nm）；`--reanchor-gesture` 整段 6/6，但会标 `reanchored`、不是纯输入 |

## 五、发布前验收命令

```bash
python3 scripts/nx.py --version
python3 scripts/nx.py doctor
bash scripts/check_offline.sh
python3 scripts/nx.py verify-pack
python3 scripts/nx.py replay --pack <包> --no-pixels
python3 scripts/nx.py pack <包>
```

外部（有网）：

```bash
python3 scripts/verify_cave_recorder_e2e.py       # 26/26
python3 scripts/verify_action_replay.py           # 16/16
python3 scripts/demo_capture_episodes.py          # 40/40（2026-10-30）
```
