# 我们记录了什么

## 校对内容

一次校对结束后会留下一个文件夹，里面大致是四类内容。

**画面**。Neuroglancer 每次比较明显的视角变化都会记一份完整状态：相机中心在哪、
放多大、切片朝哪个方向、哪些层开着、选了哪些段、面板怎么摆。画面变化到一定程度
还会拍一张 PNG——换缩放档、平移过半屏、转视角超十度、切图层、改选中集、
停住五秒不动、手动打检查点，这几种情况各拍一张。每张图绑着它对应那一刻的状态，
所以"第 40 秒他眼前是什么样"可以直接调出来。

**动作**。鼠标按下、拖动、抬起，滚轮滚了多少，键盘按了什么，按发生顺序记着，
坐标是页面像素。回放的时候这些动作会被逐条重放，视图跟着当时的动作自己走过去。

**指针位置**。每次视角变化会顺带记下鼠标悬停处的三维坐标；周期采样里带上页面像素
位置和命中的分割段。和相机中心、当前可见宽度放在一起，能回答"他这一刻在看哪一片、
鼠标压在哪个体素上、在操作哪个神经元"。这些字段记录的是鼠标指向的位置。

**人写的内容**。「打检查点」是他主动标"这里值得记一笔"，「备注」是他写下的文字，
提交记录说明他点了提交、提交了什么。这一类由人主动写，上面三类由程序自动记。

四类内容都放在同一个会话文件夹里，事件流是同一个 `client/events.jsonl`，按 `seq` 排好。

## 回放内容

`打开.html` 从上往下是视角轨迹、鼠标落点热力图、注意点时间线、完整事件表、
服务端 op 对照、备注、截图元数据。

热力图把鼠标停留的位置按屏幕坐标分箱上色，显示指针在屏幕上集中在哪些区域。
注意点时间线每个视角变化一行：相机中心、可见宽度、那一刻鼠标指向的三维坐标、
当前选中了多少段。

工作台的时间轴拖到哪一刻，页面上就有一个红点标出那一刻指针的位置（数据来自
`pointer` 与 `mouse_sample.page`）。`nx replay` 跑的回放更细：在真实页面里逐条
重放鼠标和键盘，红点跟着走；截图和逐段像素比对也在这条路上做。

一次给的坐标在数据范围外，一次瓦片没加载出来。等真实数据下有一次成功命中后启用。

待后端补充接入。
