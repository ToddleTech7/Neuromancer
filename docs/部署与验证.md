# 部署与真机验证

采集怎么起、参数怎么填，看 [使用说明](使用说明.md)。这一页讲两件事：
真机上怎么确认采集器工作正常，以及还没在真实环境验过的项。

## 一、上线自检（5 分钟）

```bash
python3 scripts/nx.py collect
```

先跑 `python3 scripts/nx.py doctor`，必需项全 PASS 再开始。

窗口打开后逐项确认：

| # | 操作 | 预期 |
|---|---|---|
| 1 | 页面加载完 | 左下角出现采集面板，状态栏显示「录制中」 |
| 2 | 缩放、拖拽 | 「事件」计数增长 |
| 3 | 点一个分割段 | 段高亮；保存后 `selection_change` 里能看到这个 id |
| 4 | 点「备注」写一行 | 保存后 `notes` 里有这行文字 |
| 5 | 点「诊断」 | 缩放来源、触发次数、已出图都显示数字 |
| 6 | 点「结束并保存」 | 终端打出 `[sink] 已保存 results/manual_sessions/<会话>` |
| 7 | 打开包里的 `打开.html` | 能看到视角轨迹、鼠标热力图、事件表 |
| 8 | 跑 `nx.py verify-pack <包>` | RESULT: PASS，无哈希/PNG 错误 |

## 三、会话包怎么处理

采集结果直接在 `results/manual_sessions/<会话>/`，不需要手工搬运。

```bash
python3 scripts/nx.py                          # 工作台：看包、回放、派生
python3 scripts/nx.py replay --pack <包路径>     # 命令行回放
python3 scripts/nx.py pack                     # 看包里有什么（只读）
python3 scripts/nx.py recover --list           # 崩溃后从草稿恢复
```

## 四、安全边界

- 采集器只读：不改工作人员视野、选择、分割
- 采集服务默认只监听 `127.0.0.1`；只有显式 `--host 0.0.0.0` 才开放局域网，且应只在对端可信时使用
- 只记录本页面内的输入，不记录其它应用的输入
- 采集故障不阻断校对：面板报错、服务掉线都不影响继续操作
- 服务端 op log 是编辑的权威记录；客户端采集是过程证据，两者按会话/时间戳关联，互不冒充
