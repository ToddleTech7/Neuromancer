# 关键帧触发规则

这份文档说明"什么时候拍一张图"。实现位于 `scripts/cave_recorder.user.js` 的
`semanticShots()` / `checkDwell()` / `checkpoint()`，面板上点「诊断」可以看当前判定过程。

---

## 触发条件

| `moment` | 判据 | 阈值 | 同类限流 |
|---|---|---|---|
| `scale_change` | 与**上次拍照时**比，`crossSectionScale` 或 `projectionScale` 跨档 | **1.5 倍** | 1.5 s |
| `view_change` | 中心点移动 > 半个屏幕 | **0.5 × 可见宽度**（`nm_per_px × panel_px`；4panel 不能用整张 canvas 宽度） | 1.5 s |
| `view_change` | 切片朝向或 3D 相机朝向变化 | **10°** | 1.5 s |
| `layer_change` | `visibleLayers` 变了 | 变了就拍 | 1.5 s |
| `selection_change` | 分割选中集变了 | 变了就拍 | 1.5 s |
| `dwell` | 中心 + 选中集 + 可见层都不变 | **5 s** | 只拍一次 |
| `checkpoint` | 手动点「打检查点」/ 开场 / 结束并保存 | — | 无 |
| `note` | 点「备注」后自动补拍（`note_keyframe` 开时） | — | 由备注内容触发，`detail.note_id` 指向备注 |

两个例外：

- **开场基线**：`session_start` 时 canvas 还没画完，延迟 **600 ms** 补拍一张
  （`detail.reason = 'session_start'`、`auto = true`）。
- **`session_stop` 不拍**：它是内部停止事件，紧接导出。面板的「结束并保存」先打
  `session_end`，等这张异步图落进 `R.shots` 后再导出；因此最终包会多一张
  `checkpoint/session_end` 图。

---

## 为什么阈值是这些数

| 参数 | 值 | 依据 |
|---|---|---|
| 缩放 1.5 倍 | 相对上次**拍照**，不是相邻两帧 | 滚轮一格约 ×1.2；按相邻帧算永远够不到，连续放大 10 倍也一张不拍（2026-10-29 实测踩过） |
| 移动半屏 | `nm_per_px × 画布宽度 × 0.5` | 跟缩放级别走；固定 nm 阈值在放大时会疯狂触发、缩小后又几乎不触发 |
| 转动 10° | 两个 3×3 旋转矩阵夹角 `acos((tr(AᵀB)−1)/2)` | 小于 10° 视觉上几乎一样，拍了是冗余 |
| 限流 1.5 s | 同类型之间 | 拖动时每帧都在变，不限流会 1 秒几十张 |
| 停留 5 s | `dwell_ms` | 短于 5 s 会把"随手划过去"也当成在看 |

## 每张图的 `detail` 字段

`client/shots/shots.jsonl` 每条都带 `detail`，回答"**为什么拍、变化多大**"。
所有类型都有：

| 字段 | 含义 |
|---|---|
| `since_last_shot_ms` | 距上一张图多少毫秒 |

### `scale_change`

```json
{"axis":"cross_section","cross":4.63,"prev_cross":12.18,"ratio_cross":0.38,
 "proj":10427.9,"prev_proj":10427.9,"ratio_proj":1.0,
 "threshold":1.5,"since_last_shot_ms":8200}
```

`axis`：`cross_section`（2D 截面）或 `projection`（3D 相机）。

### `view_change`

```json
{"kind":"pan","moved_nm":3200,"view_nm":6400,"moved_ratio":0.5,
 "turn_deg_cross":null,"turn_deg_proj":null,
 "threshold_ratio":0.5,"threshold_deg":10,
 "position":[...],"prev_position":[...]}
```

`kind`：`pan`（平移） / `slice_rotate`（换切片朝向） / `camera_rotate`（转 3D 相机）。

### `layer_change`

```json
{"visible_layers":"B+seg","prev_visible_layers":"B+seg+em"}
```

### `selection_change`

```json
{"selected":"{...}","prev_selected":"{...}",
 "added":["1956846"],"removed":[]}
```

### `dwell`

```json
{"dwelled_ms":5120,"threshold_ms":5000,"center":[190587,114102]}
```

### `checkpoint`

```json
{"reason":"manual","auto":false,"checkpoint_index":2}
```

`reason` 取值：`manual` / `session_start` / `state_change` / `state_change_forced`。
`auto=true` 表示不是人点的。

## 面板状态栏怎么读

```
录制中 ｜ 事件 3259 ｜ 缺口 0
图 9 张：检查点 1（自动 1） · 缩放 2 · 视角 0 · 选中 2 · 图层 0 · 停留 3
```

- **检查点 1** = 人手动点的次数
- **（自动 1）** = `session_start` 基线 + 自动检查点
- 后面按 `moment` 分类计数，加起来是总图数

## 想调阈值改哪里

全部在 `scripts/cave_recorder.user.js`：

| 想改 | 位置 | 说明 |
|---|---|---|
| 缩放倍数 | `semanticShots()` 里的 `const RATIO = 1.5` | 调小更容易触发 |
| 移动半屏 | `movedNm > viewNm * 0.5` | `0.5` → `0.25` 更灵敏 |
| 转动角度 | `cd > 10` / `pd > 10` | 单位度 |
| 限流 | `fire()` 里 `now - last[reason] < 1500` | 毫秒 |
| 停留时长 | `R.config.dwell_ms`（默认 5000） | 可在「设置」里改，写 localStorage |
| 开关 | `R.config.semantic_keyframe` | 关掉后只剩检查点 |

改完跑：

```bash
node --check scripts/cave_recorder.user.js
python3 scripts/nx.py collect      # 重新注入
```

已经在跑的采集窗口不会热更新；每次 `nx collect` 会重新注入最新脚本。

## 已知限制

- **某轴拿不到值**：`vp.scale_source` 会记 `state` / `viewer` / `none` / `partial`。
  `none` 时该轴为 `null`，不参与判据，另一个轴照常工作。
- **`crossSectionScale` 在 3D-only 布局下不变**：只转 3D 时靠 `projectionScale` 和
  `position` / 朝向判据，不会因为 2D 没动就漏拍。
- **`selectedLayer` 抖动**：`selection_change` 只看选中集，层切换不算选中变化。
- **限流会有意丢图**：连续拖动 1 秒只留 1 张，这是设计不是 bug。
- **`dwell` 不分屏**：多面板布局下只看主画布中心。

## 验证方式

面板点「诊断」：

```text
缩放来源: state
cross / proj: 4.634611 / 10427.971093
最近缩放: 26.172s:4.63/10427.97  26.239s:4.63/10427.97
最后一次判断: 缩放 4.63→4.63（1x） 移动 0/23729nm 转向 -° 开关=开
触发次数: selection_change=2 scale_change=2
已出图: checkpoint=2 dwell=3 selection_change=2 scale_change=2（共 9）
```

`最后一次判断` 显示上一次比较的两个值、比值、移动量、屏幕宽度和转向角，
可以看出是没到阈值，还是值没有变化。
