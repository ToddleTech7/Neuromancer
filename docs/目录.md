## 维护规则

1. 一个问题只有一个权威文件；其他文件写一行引用。
2. 新文档先在本页登记，再写内容。
3. **当前**数字以本页 + 开发记录最近一条为准；[评审报告](评审报告.md) 是某次快照，引用时注明日期。
4. 过时的内容直接删，删之前在 `开发记录.md` 记一条「删了什么、为什么」。
   初代版本保持干净；此后每次开发都留记录。
5. **写法**：描述性陈述。内容用标签分块（`校对内容：` `回放内容：` `后续工作：`）；
   还没做的事写成「后续工作」，不写成「不能做什么」。
