## 能力边界（附实测理由）

| 项 | 现状与理由 |
|---|---|
| 渲染器内部队列（tile/chunk/mip） | 不采集：真状态在 Worker；页面只能看到 `/info`、`/state` 和最外层的 shard/mip。回放像素差异按 LOD/瓦片加载时序解释，不当作输入回放误差 |
| 当前工具 | 本构建 `viewer.tool` 不存在，改用 DOM 读工具栏状态 |
| 采样率 | 日志粒度是产品决策（D10）→ 做成 `move_sample_ms` 可配 |
| 像素 vs state 绑定 | 用 `state_sha` 绑定（画面差异会把"加载中"误判成"人动了"） |
